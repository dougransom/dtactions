2024//6/10: This directory was in the Unimacro repository, but is now put here, in dtactions.

The file "Unimacro.vch" is renamed to "Uniactions.vch".

The file "Uniactions.vch" holds the "USC-commands" ("Uniactions Shorthand Commands"), and the accompanying actions are also in this dtactions repository. So now, there remains no dependency between Vocola2 and Unimacro (as I am aware of).

Starting April 2026 the renaming from Unimacro.vch to Uniactions.vch has taken place, with release 2.0.0.
